# Contributing

1. Open an issue describing the missing paper, metadata correction or analysis change.
2. Do not commit publisher PDFs or credentials.
3. Preserve raw source exports; add cleaning or normalization as a separate reproducible step.
4. Distinguish core physical loops, partial/enabling loops and adjacent software-only agents.
5. Record evidence stage and avoid inferring clinical autonomy from simulation or engineering demonstrations.
6. Run `python scripts/validate_repository.py` before committing.

Suggested commit prefixes: `data:`, `literature:`, `analysis:`, `figure:`, `docs:` and `fix:`.
