# Manuscript material

`recovered_versions/` contains normalized copies of every manuscript-like text file found in the active workspace. The filenames express a practical ordering inferred from the uploaded names and file contents; they are not authenticated creation timestamps.

`drafted_sections/` contains the three standalone sections developed in the visible conversation. They remain drafts and should be integrated only after citation and argument-level review.

The repository does not select a single canonical manuscript automatically. The largest recovered draft is `2026-08-04_v06_full_draft_8869w.tex`, but word count alone is not evidence that it is the preferred or final version.
