# Generated results

These files are deterministic or traceable derivatives of the recovered manuscript and literature registry:

- `manuscript_inventory.csv`: size and SHA-256 of recovered/drafted manuscript and source artifacts.
- `citation_usage.csv`: citation key, file, count and line numbers.
- `missing_citations.csv`: missing, unresolved or provisional citations that need action.
- `section_word_counts.csv`: approximate counts after simple LaTeX cleaning.
- `run_manifest.json`: runtime, input/output hashes, Git commit when available, and record counts.

They are research-management outputs, not experimental or clinical results.
