# Source archive policy

The original ZIP releases and their hashes are retained under `archive/original_release_archives/` for forensic provenance. Unpacked copies of smaller historical packages are stored under `archive/imported_packages/` so earlier manuscript, diagnostic-agent and recovery workflows remain inspectable.

The large `embodied-medical-detection-review-research` package forms the current repository base. Its 40 PDFs are moved to `local_only/papers/` before the Git commit because redistribution permissions are not established.
