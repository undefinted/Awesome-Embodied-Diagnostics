# Clinical Detection and Intervention：最终工作分类（中文）

版本：taxonomy v1.0  
分类单位：**一项研究中被评价的一个诊断证据获取阶段**，而不是整台机器人、整套平台、整篇论文或一种传感模态。

## 一、最终主分类

### 1.1 Active observational sensing / 主动观察式感知

系统根据已有观测改变传感器的位置、姿态、视点、接触状态、覆盖范围、轨迹或采集参数，以取得新的**在体观察证据**。组织没有被有意扰动以产生诊断响应，也没有取出材料进行离体分析。

子任务：

- A1 体表接触式扫描与传感器布置
- A2 体表非接触式对准与扫描
- A3 有缆腔内或腔道内观察与导航
- A4 无缆体内观察与导航
- A5 导管、血管内、管道内或经皮探头在体感知

超声、OCT、Raman、DRS、光声、HSI、RGB 视觉和听诊均为**模态标签**；眼科、甲状腺、颈动脉、胃肠、肺、皮肤和创面均为**部位或场景标签**；机械臂、探头、内镜、胶囊和导管均为**载体标签**。

### 1.2 Response-eliciting interactive diagnosis / 诱发响应式交互诊断

系统有意施加受控机械、声学、电、磁、神经生理或其他生理扰动，并把由此诱发的力学、生理或功能响应作为诊断证据。

子任务：

- R1 准静态接触、触诊与压入
- R2 动态机械或声学激励
- R3 施加运动、载荷与功能激发
- R4 电、磁或神经生理刺激—响应映射
- R5 生理挑战与受控调制

接触力控制并不自动等于 1.2。若力只用于保持超声耦合或保障安全，任务仍属 1.1；只有当受控加载后产生的形变、波动或生理响应本身被解释为诊断证据时，才归入 1.2。

### 1.3 Diagnostic sample acquisition / 诊断性样本获取

系统通过物理动作取得组织、细胞、血液、体液、微生物或其他材料，并将其用于离体病理、细胞学、生化、微生物或分子分析；取材位置、轨迹、重复采样或样本充分性至少有一项进入被评价的闭环。

子任务：

- S1 经皮针式组织采样
- S2 血管血液采样
- S3 有缆腔内或腔道内组织/体液采样
- S4 无缆或胶囊式体内采样
- S5 体表或黏膜标本采集
- S6 其他自适应体液或排泄物采集

仅完成活检导航、靶向或针具定位不足以纳入 1.3；研究必须评价实际诊断材料获取、诊断产出、标本质量/充分性，或能改变采样动作的反馈。输注、消融、引流和植入等纯治疗动作排除。

## 二、互斥判定顺序

1. 是否取得用于离体分析的诊断材料，且取材或充分性属于被评价的闭环？是：1.3。
2. 否则，是否有意扰动组织或生理状态，并解释诱发响应？是：1.2。
3. 否则，反馈是否改变下一次在体观察的采集配置？是：1.1。
4. 三者均否：不作为完整具身诊断系统纳入，可保留为支撑技术。

该顺序用于判定**一个阶段**，不用于强行给整个平台贴唯一标签。例如，机器人支气管镜可以同时包含 1.1 的观察/导航阶段和 1.3 的活检阶段；若论文分别评价二者，应建立两条相互关联的任务记录。

## 三、证据表必须独立记录的标签

- 传感模态
- 解剖部位与临床适应证
- 进入路径
- 物理载体
- 行动权限（人类、共享控制或系统）
- 闭环程度（开环、局部控制、证据自适应或端到端）
- 最终诊断证据类型
- 验证环境和证据成熟度

## 四、计数规则

旧的论文级互斥柱状图已经撤回，因为旧子任务把模态、进入路径和载体混在同一层，而且数据来自自动题名筛选而非完成的全文纳入。

后续正式统计应分别报告：

1. Clinical Detection and Intervention 的唯一论文数；
2. 每个主机制的唯一论文数；
3. 每个子任务的 task–study pair 数；
4. 跨机制重叠；
5. 经全文核验、明确形成反馈闭环的系统数。

一篇论文若评价多个诊断证据获取阶段，可以对多个机制贡献 task–study pair，因此各机制数量之和可以大于大领域唯一论文数。只有在明确声明“按主要终点分配”的敏感性分析中，才可制作论文级互斥图；它不应作为主分类图。

## 五、当前证据状态

本分类可作为综述和 PPT 的稳定工作版本。数量结论仍需在该口径下完成统一公开来源检索、摘要/全文筛选、排除原因记录、预印本—会议—期刊版本合并和任务级编码。公开可见题录以及自动识别到的公开全文位置只是发现层，不能替代纳入判定、闭环核验或临床成熟度评价。
