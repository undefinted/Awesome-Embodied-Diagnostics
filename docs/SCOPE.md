# Scope and evidence boundary

The unit of analysis is a sensing–decision–action–feedback loop that adaptively acquires diagnostic evidence across a patient, sample, instrument or care environment.

## Three record classes

1. **Core embodied diagnostic system:** a decision changes a physical measurement or diagnostic action and the outcome updates later decisions.
2. **Partial loop or enabling capability:** active localization, feedback control or robotic execution is present, but diagnostic-level feedback is not closed.
3. **Adjacent sequential software agent:** questions, tests or EHR actions are selected sequentially, but physical acquisition is human-mediated or simulated.

Autonomy level, evidence maturity and clinical utility must be recorded separately.
