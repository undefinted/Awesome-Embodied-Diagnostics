# P5 public visible / public available 方法说明

检索冻结日期：2026-08-13；时间范围：2000-01-01 至 2026-08-13。

## 口径

- **Public visible research record**：在 OpenAlex、Europe PMC、Crossref 或 arXiv 至少一个公开索引中可检索到书目记录，并满足任务级题名规则的 DOI/规范题名去重候选。
- **Public available research record**：上述候选中，由 Europe PMC、arXiv 或 OpenAlex 元数据识别到合法公开全文或完整预印本位置者。它是全文位置发现，不是逐篇许可证审计。
- **Public project/system**：有机构项目页、项目官网、原始公开论文或公开预印本能够明确对应的具名系统。项目单独列账，不与论文数量相加。

## 覆盖任务

机器人超声；机器人胃肠内镜巡检；磁控/主动胶囊内镜；机器人支气管镜观察/导航；机器人 OCT；机器人听诊；机器人眼底/裂隙灯成像；机器人耳镜检查；机器人皮肤/创面表面扫描；机器人光谱/光学扫描；机器人喉镜/口腔检查。

分类单位是具体诊断任务或阶段，而不是整台平台。支气管镜导航可进入主动观察，活检阶段则进入采样式交互。

## 检索与筛选链

1. 为 11 个任务构建同义词和平台词，共运行公开索引查询。
2. API 返回记录按 DOI 优先、规范化题名其次跨库去重。
3. 高召回题名/摘要规则建立候选池。
4. 更严格题名规则排除治疗、手术、纯图像分类、综述和非医学应用。
5. 对代表性样本进行人工误纳入审计并迭代排除词。
6. 公开全文位置根据仓储、预印本和 OA 元数据识别。

## 当前状态

当前图表统计的是**题名规则候选**，不是已经完成全文人工纳入的全部研究。Crossref 和 arXiv 部分补漏查询在网络恢复后的运行中触发 429 限流，错误均保留在检索日志；OpenAlex 和 Europe PMC 主检索完整返回。由于公开索引本身存在覆盖差异，不能将结果称为全球绝对总数。

若用于正式论文中的文献数量结论，仍需：双人题名摘要筛选、全文筛选、排除原因记录、预印本与期刊版本人工合并、OA 许可证核验和 PRISMA 流程。

## PPT 推荐脚注

> Public-visible = 公开索引题名规则候选；public-available = 识别到公开全文位置。2000–2026-08-13，按 DOI/规范题名去重。候选计数并非系统综述全文纳入数；部分 Crossref/arXiv 补漏查询受限流影响。
