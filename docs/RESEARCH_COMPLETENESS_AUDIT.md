# 医学检测具身智能应用：研究完整性与证据审计

更新日期：2026-08-13

## 结论先行

本项目目前不能声称“已穷尽所有相关研究”。更准确的状态是：

- 临床检测三类任务已形成跨来源候选语料、任务归一化和去重结果，可用于研究集群的范围性描述；候选计量仍不是最终纳入量。
- 机器人超声、机器人 OCT、磁控胶囊内镜、主动触诊、TMS 映射、机器人活检/采血/拭子等关键方向已核验若干原始研究。
- 实验室诊断和日常监测已经建立代表性证据链，但尚未完成逐库、双人筛选意义上的系统综述。
- 机器人光谱扫描、活检样本充分性闭环、跨仪器异常恢复、环境感知后的主动确认，是目前最明显的证据薄弱区。

“完整”在本项目中只允许表示：预先定义数据库、时间窗、语言和纳排标准后，检索式与筛选记录可复现；它不表示可以证明世界上不存在漏检论文。

## 三个状态标签

1. **已系统计量**：保存了查询式、原始命中、规范化任务标签和去重结果；仍需人工全文筛选才能形成正式论文数。
2. **已核验代表性证据**：关键数字和边界由原始论文、试验注册或官方文件核对；不能据此声称覆盖全部研究。
3. **待系统筛选**：已识别任务与代表作，但候选池或全文筛选不完整；PPT 中不得展示为精确领域规模。

逐任务状态见 `data/presentation/domain_coverage_audit.csv`。

## 纳入边界

### 严格核心层

研究必须包含物理载体或可控物理过程，且系统输出能够改变后续观察、刺激、采样、检测或验证动作；行动后的新结果进入后续状态更新。

### 邻近支持层

研究可缺少完整闭环，但提供关键能力，例如自主对准、质量评估、病灶识别、样本充分性判断、反射检测或异常恢复。此类研究必须明确标注为 supporting capability。

### 排除或单列

- 仅对既有数据进行分类、分割或报告生成；
- 完全固定轨迹且不使用反馈调整；
- 主要目标为治疗，诊断证据获取只是附带功能；
- 虚拟 EHR/问诊代理而无新的物理采集动作；
- 仅证明硬件可移动，但没有诊断证据或状态反馈。

## 推荐检索流程

1. 核心数据库：PubMed/Europe PMC、Web of Science、Scopus、Embase、IEEE Xplore、ACM DL。
2. 补充数据库：Crossref、OpenAlex、DBLP、arXiv、ClinicalTrials.gov。
3. 每个任务保存完整布尔式、检索日期、数据库版本和原始命中数。
4. DOI、PMID、arXiv ID 和规范化题名联合去重；预印本与正式版本合并。
5. 题名摘要筛选后进行全文筛选；拟作为正式系统综述数据时采用两名筛选者并报告分歧处理。
6. 一篇论文中的一个系统/任务阶段为一行，平台可多标签。
7. 分开报告：候选命中数、纳入研究数、人体研究数、前瞻性研究数和临床试验数。

数据库检索模板见 `data/presentation/search_strategy_registry.csv`。目前没有机构订阅接口的数据库，应由研究团队在有权限的终端运行并回填结果。

## 证据陈述规则

- 原始事实：必须有可定位的一手来源及研究设计、样本量和比较对象。
- 合理推断：明确使用“suggests / indicates / may”并说明推断依据。
- 研究设想：不得与已实现能力混写。
- 计量结果：只称为“当前保存语料中的候选数”，不得称为全球论文总数。
- 成熟度：分别评价物理任务成功、测量质量、诊断效能、人体可行性、前瞻性效用、部署与监管。

## 本轮核验带来的主要修正

- 自主眼科 OCT 已有人体无接触自主对准和急诊人群外部验证，不应笼统归为“仅幻模/前临床”；但诊断模型尚未明确驱动自动复扫。
- 磁控胶囊内镜已有前瞻性人体研究，且实时自动质量控制已有随机试验；质量提示辅助操作者不等同于系统自主改变胶囊运动。
- 机器人触诊已覆盖幻模、离体及动物组织，但真正以不确定性选择下一触点的工作仍主要处于幻模/前临床。
- 关节松弛度和痉挛评估多为标准化定量测量或遥操作，不宜全部称为自主诊断闭环。
- 实验室自验证通常只改变报告放行或人工复核，不自动执行物理复检；数字微流控的失败检测与纠偏才是更直接的物理闭环实例。
- 日常可穿戴和环境感知的大量研究只做持续感知。DETECT-AHEAD 这类“异常后提示家庭检测”的试验更接近 detect-to-confirm 闭环，但行动仍由人执行。
